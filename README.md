🔢 Counter App

📖 Overview

This Counter App is a beginner-level JavaScript project created during Week 2 of my JavaScript learning journey. The project performs basic counter operations, allowing the counter value to be incremented, decremented, and reset. It was built to strengthen my understanding of JavaScript fundamentals by applying them in a simple, practical program.

---

✨ Features

- Increase the counter value
- Decrease the counter value
- Reset the counter to zero
- Simple and beginner-friendly interface

---

🛠️ Technologies Used

- HTML5
- JavaScript (ES6)
